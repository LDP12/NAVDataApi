    Precision & reporting notes

    NAV and share quantities show at least four decimal places; all additional API precision is retained. Net assets use the API’s two-decimal, rounded valuation. Currency snapshots sum those values exactly and may span different observation dates. The graph uses approximate coordinates only; its text and the table preserve exact values.

    CSV exports the current table view with original decimal tokens. All cells are quoted; formula-like values (including after whitespace) are prefixed with an apostrophe. Import decimal columns as text in spreadsheets to avoid their numeric precision limits. API keys are never written to browser storage. Disconnect clears this page’s data; previously downloaded exports remain on your device.
